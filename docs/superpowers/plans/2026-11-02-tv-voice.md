# TV screen (Google TV layout) and voice: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lay out the TV screen like the Google TV phone remote, and add a hold-to-talk mic button
that works on every supported TV. On Android TV it sends real voice to the TV's assistant. On LG and
Samsung the phone does speech-to-text on the device and types the text into the TV.

**Architecture:** Mic capture is a small new Expo native module (`modules/mic-pcm`) that emits
16-bit PCM chunks. Android TV voice adds three Remote v2 messages and a voice session on `AtvRemote`,
exposed through an optional `startVoice` on `LinkDriver` and `DeviceHub`. Dictation wraps
`expo-speech-recognition` with on-device recognition required, and never falls back to the network.
The screen picks the voice path from the capabilities.

**Tech stack:** Expo SDK 58, TypeScript, Jest, Kotlin (Android `AudioRecord`), Swift (iOS
`AVAudioEngine`), and `expo-speech-recognition`.

**Spec:**
- `docs/research/2026-11-02-tv-voice.md` (voice protocol, decisions)
- `docs/design/one-remote-mockup.html` (figures 2a and 2b)

## Global constraints

- Bun only (`bun add`, `bunx`, `bun run`). Never npm, yarn or pnpm.
- Commit as `Devansh Choubey <devanshc13@gmail.com>`, with Conventional Commits. The hook rejects
  `merge:`. Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Do not push.
- Privacy: local network only. No cloud speech. Dictation must set `requiresOnDeviceRecognition:
  true`. When the phone cannot recognise speech on the device, dictation is unavailable. There is
  no fallback.
- `bun run test`, `bun run typecheck` and `bun run lint` must pass at every commit.
- UI composes from `@/ui` primitives. Raw React Native visuals are lint-banned in screens.
  User-facing text goes in `src/i18n/en/*.ts`.
- Android TV voice wire format (from tronikos/androidtvremote2):
  - feature bit `VOICE = 8`;
  - start by sending `KEYCODE_SEARCH` (84), then wait up to 2000 ms for `remote_voice_begin`
    (RemoteMessage field 30: `session_id` = 1, `package_name` = 2) and echo
    `remote_voice_begin{session_id}` back;
  - audio goes in `remote_voice_payload` (field 31: `session_id` = 1, `samples` = 2 bytes) as PCM
    16-bit little-endian, 8000 Hz, mono, in messages of at most 20480 bytes; a message under 8192
    bytes is zero-padded to 8192;
  - end with `remote_voice_end` (field 32: `session_id` = 1). One session at a time.
- Hold to talk: press the mic to start and release to send. With no text field open on LG, Samsung
  or Android TV, show `tv.voiceNoField` "Open a search box on the TV first".

## Review focus

1. Release before the voice session starts (a tap, not a hold): the session still ends cleanly, and
   no mic stays open.
2. The screen loses focus, the app goes to the background, or the TV disconnects mid-hold: the mic
   stops and the session ends. No leak, no stuck "listening" state.
3. Mic permission denied: one plain error line. The button stays, and no crash.
4. A TV that does not negotiate the voice bit, or does not answer `remote_voice_begin` within 2 s:
   fall back to dictation if it is available, otherwise show `tv.errNotSent`.
5. Dictation returns empty text: send nothing and show nothing.

  import only in `src/voice`, in the same way `lan-socket` is limited to `src/transport`.

Interface (in `src/voice/mic.ts`):

```ts
export interface MicSession { stop(): void }
export interface Mic {
  /** Asks for permission if needed; resolves false when denied. */
  requestPermission(): Promise<boolean>;
  /** Starts capture: PCM16 little-endian mono at `sampleRate`, delivered as chunks. Throws when
   *  the mic is busy or permission is missing. */
  start(sampleRate: number, onChunk: (pcm: Uint8Array) => void): MicSession;
}
export function createNativeMic(): Mic;
```

- Native side:
  - The module emits `onChunk` events with base64 PCM, about every 100 ms. The wrapper decodes them
    to `Uint8Array`.
  - Android: `AudioRecord` with `MediaRecorder.AudioSource.VOICE_RECOGNITION`,
    `ENCODING_PCM_16BIT`, `CHANNEL_IN_MONO`, the requested rate, read on a background thread.
  - iOS: an `AVAudioEngine` input tap, converted with `AVAudioConverter` to Int16 mono at the
    requested rate. Set the audio session category `.record` while capturing, and deactivate it on
    stop.
  - `stop()` is idempotent.
- The fake records `start` and `stop` calls and lets tests `emit(chunk)`. It can be set to deny
  permission.

Steps:

- [ ] Jest tests for the wrapper, with the native module mocked:
  - base64 events become `Uint8Array` chunks;
  - `stop` removes the listener and calls native stop once;
  - a denied permission resolves false.

### Task 3: Android TV voice session (protocol)

**Files:**
- Modify:
  - `src/androidtv/constants.ts` (`FEATURES = 111` and the comment);
  - `src/androidtv/messages.ts`;
  - `src/androidtv/remote.ts`;
  - `src/androidtv/testing/fakeAtv.ts`.
- Tests: `tests/androidtv/` (the existing messages, remote and fake test files).

Interfaces:

- `RemoteIn` gains `{ kind: 'voiceBegin'; sessionId: number; packageName?: string }`.
- `RemoteOut` gains:
  - `{ kind: 'voiceBegin'; sessionId: number }`
  - `{ kind: 'voicePayload'; sessionId: number; samples: Uint8Array }`
  - `{ kind: 'voiceEnd'; sessionId: number }`
- `AtvRemote`:
  - `get voiceSupported(): boolean`. True when the negotiated features include 8.
  - `startVoice(timeoutMs = 2000): Promise<number>`. It sends key 84, waits for `voiceBegin`, echoes
    it, and resolves with the session id. It rejects with `DeviceError('notSent')` on a timeout,
    when voice is unsupported, or when the stream closes. It throws `notSent` when a session is
    already open.
  - `sendVoice(sessionId: number, pcm: Uint8Array): void`. It splits the data into 20480-byte
    messages, pads any message under 8192 bytes with zeros, and does not log the samples.
  - `endVoice(sessionId: number): void`. It is idempotent and clears the open session.
- The fake TV:
  - advertises 615 by default (voice bit included);
  - on key 84, answers `voiceBegin{sessionId: 7, packageName: 'com.google.android.katniss'}`;
  - records the payload bytes and the end;
  - has an option for not answering.

  - `startVoice` times out at 2000 ms when the fake is silent;
  - `voiceSupported` is false when the TV's features lack 8;

Interface:

```ts
export interface Dictation {
  /** True only when this phone can recognise speech fully on the device, now. */
  available(): Promise<boolean>;
  /** Starts listening with requiresOnDeviceRecognition: true. `stop()` ends it and resolves with
   *  the final text ('' when nothing was heard). Rejects on a recognition error. */
  start(): { stop(): Promise<string> };
}
```

- `available()` uses the library's on-device support check (read its `.d.ts` in node_modules).
  - On Android it also needs the device locale (or `en-US`) among the installed on-device locales.
  - Any error means false. It never returns true for network-only recognition.

The mic button (bottom-right slot, the filled circle from the mock):

- **Which path it takes:**
  - `caps.voice` true: native voice.
  - Otherwise, when `caps.text !== false` and `dictation.available()` resolved true: dictation.
  - Otherwise the slot stays empty.
  - Check availability once per screen focus.
- **Native voice:**
  - on press-in, `mic.requestPermission()`, then `hub.startVoice(deviceId)`, then
    `mic.start(8000, (c) => session.push(c))`;
  - on press-out, `mic.stop()` then `session.end()`.
  - If the press-out comes before the start resolves, end right after the start resolves (review
    focus 1).
  - If `startVoice` fails and dictation is available, use dictation for this hold.
- **Dictation:**
  - on press-in, `dictation.start()`;
  - on press-out, `stop()`, and send the text, when it is not empty, with `hub.send` as
    `{ kind: 'tv.text', text }`.
  - A `notSent` error whose message mentions no text field shows `tv.voiceNoField`. Other errors
    use the usual error line.
- **While held:** show `tv.listening` "Listening…" as a live caption. The accessibility label is
  `tv.voice` "Hold to talk".
- **Cleanup:** losing focus, going to the background, or unmount stops everything (review focus 2).
- **Permission denied:** show `tv.micDenied` "Allow the microphone for One Remote in your phone's
  settings." (review focus 3).
