# TV Groundwork (every brand) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the TV layer brand-neutral, so that the Android TV and Samsung lanes only add a folder
and one registry line each. LG must keep working unchanged.

**Architecture:**

- `src/core` gets one `TvLink` union, plus helpers, `TvCaps` and a brand-neutral `TvSetup`.
- `src/tv` holds the shared pieces:
  - Wake-on-LAN;
  - the transport interface;
  - the brand registry;
  - the composite setup that runs every brand's discovery, with one shared subnet probe.
- `src/webos` becomes the first registered brand.
- The native `lan-socket` module gains three features, each behind the local-only check, and the
  phone's client identity:
  - a raw TLS byte stream;
  - one-shot HTTP(S) requests;
  - mDNS browsing.

**Tech Stack:**

- Expo SDK 58 and TypeScript, Jest, Bun.
- Kotlin for Android: OkHttp, `SSLSocket`, Android Keystore, `NsdManager`.
- Swift for iOS: `Network.framework` (`NWConnection`, `NWBrowser`), Security / Keychain.

**Spec:** `docs/superpowers/specs/2026-11-01-every-tv-design.md` (sections 4, 5.1, 5.3–5.6, 6 and 7),
on top of `docs/superpowers/specs/2026-10-30-one-remote-design.md`.

## Global Constraints

- **Toolchain:** Bun only (`bun install`, `bunx`, `bun run`); never npm, yarn or pnpm.
- **Git:**
  - Commit as `Devansh Choubey <devanshc13@gmail.com>`, with Conventional Commits.
  - End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Never `merge:` as a type. Never push.
- **Purity:** `src/core`, `src/device`, `src/tv`, `src/webos` (and later `src/androidtv` and
  `src/samsung`) are pure TypeScript, with no React Native or Expo imports. ESLint enforces this; add
  `src/tv` to that rule.
- **Networking:**
  - Only `src/transport` imports `modules/lan-socket`. `fetch` and `XMLHttpRequest` stay banned.
  - Every outgoing address is a literal private, link-local or loopback IP, checked in native code
    before dialling (`LocalHost.isLocalLiteral` on Android, and its Swift twin).
- **TLS:**
  - It is trust-on-first-use: `pairing: true` accepts and reports the leaf certificate's SHA-256.
  - `pinSha256` accepts only that certificate. Neither means refused.
  - Private keys never cross into JavaScript.
- **Tests:**
  - Existing tests may be edited for renames and moves. What they check must not get weaker.
  - `bun run test`, `bun run lint` and `bun run typecheck` stay green after every task.
- **UI:** the UI is fixed. Only the changes in spec §6 are allowed, and they are built from `@/ui`
  primitives and `t()` strings in `src/i18n/en`.

## Review Focus

1. **One TV seen by two brands' discovery** (for example a Sony Google TV answering both mDNS and the
   probe). It must appear once in the search: same host, first registered brand wins, and a later
   hit replaces it only when its brand is earlier in the registry. Test in Task 3.
2. **Re-pair from the device sheet on an LG TV.** It must still reuse the old `clientKeyRef` and
   release the driver's notPaired latch. Test in Task 4: keep the existing `tvFollowUp` tests
   passing in their new form.
3. **A device saved before this change**, with `{kind: 'webos', …}` only and no new fields. It must
   load and work: no store migration, and no required new link field on `webos`. Test in Task 1.
4. **A `request()` to a non-local URL or a redirect.** It is refused with `ERR_LAN_NOT_LOCAL`, or by
   following no `Location` header. Test in Task 6 (Kotlin).
5. **A stream whose TV closes mid-write.** A `close` event fires once, with no crash, and later
   `write` throws. Test in Task 5 (Kotlin).

- Produces (exact):

  ```ts
  // src/tv/brands.ts
  export interface BrandSetup {
    kind: TvLinkKind;
    /** i18n key of the brand word shown in the brand list and under a found TV, e.g. 'addTv.brandLg'. */
    labelKey: string;
    pairing: 'allow' | 'code';
    /** Ports the shared subnet probe sweeps for this brand. */
    probePorts: number[];
    /** Multicast discovery only (SSDP / mDNS). Best effort; ends quietly on error. */
    discover(onFound: (tv: FoundTv) => void): Unsubscribe;
    /** Turns one host's open probe ports (only this brand's) into a TV, or null. */
    fromProbe(host: string, open: ReadonlySet<number>): FoundTv | null;
    probeHost(host: string): Promise<FoundTv | null>;
    pair(tv: FoundTv, prompts: PairPrompts, reuse?: TvLink): Promise<PairedTv>;
    /** New host for this brand's link, or null. */
    findAgain(device: Device, link: TvLink): Promise<string | null>;
  }

  // src/tv/setup.ts
  export function createCompositeTvSetup(o: {
    brands: BrandSetup[];           // registry order = priority
    transport: Pick<TvTransport, 'probe'>;
    probeMs?: number;               // default 1500, per host
    frames?: { subscribe(cb: (f: TvFrame) => void): Unsubscribe };
  }): TvSetup;
  ```

- Behaviour:
  - `discover` starts every brand's `discover`, plus one `transport.probe(unionOfPorts)`.
  - `fromProbe` is called with each brand's own ports for a host once the sweep ends.
  - Hits are de-duplicated by host. A later hit for a known host replaces it only if its brand is
    earlier in `brands`, or it is the same brand with `secure` turned true (the existing LG upgrade).
  - `probeHost` asks each brand in order and returns the first non-null. A `notLocal` error is
    rethrown at once.
  - `pair` and `findAgain` dispatch by `tv.kind` or by `tvLinkOf(device).kind`. An unknown kind gives
    `PairError('unreachable')` or `null`.

  The LG `BrandSetup` is `createWebosBrand({ transport, secrets })` in `src/webos/setup.ts`, with:
  - `labelKey: 'addTv.brandLg'`, `pairing: 'allow'` and `probePorts: [3000, 3001]`;
  - `fromProbe`: port 3000 means plain; 3001 alone means secure;
  - `discover`: SSDP only.

  `discoverTvs` stays exported for `rediscover`.

  `createServices` builds `createCompositeTvSetup({ brands: [createWebosBrand(...)], ... })`, still
  wrapped by `withTvFollowUp`. Each later lane adds its brand on its own line under a
  `// <lane> brand` slot comment in that array.
